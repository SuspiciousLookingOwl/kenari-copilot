Kenari for Copilot Chat uses your own Kenari API key to make a variety of AI models available in the model picker.

Create a key (it starts with `kn-`) in the Kenari dashboard, then paste it here. You can update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `Kenari: Set Kenari API Key`: Set or update your API key
- `Kenari: Generate Commit Message with Kenari`: Generate Git commit messages

[Get an API Key](command:kenari.getApiKey)
[Set API Key](command:kenari.setApiKey)
